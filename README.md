
# Scuffed Fighters

**Scuffed Fighters** is a 3D multiplayer fighting game developed using Unity. The project focuses on multiplayer gameplay, 3D rigged character animations and hitbox-based combat mechanics.

## Features

- **3D Fighting Gameplay** – Real-time fighting gameplay with rigged 3D character animations.
- **Multiplayer Networking** – Peer-to-peer multiplayer functionality using Unity Netcode for GameObjects.
- **Remote Procedure Calls (RPCs)** – Network communication to coordinate multiplayer gameplay.
- **Hitbox-Based Combat** – Hitbox and hurtbox collision detection for combat interactions.
- **Combo System** – Supports chained attacks through a dedicated combo system.

## Technologies

| Technology | Usage |

## Technical Highlights

### Multiplayer Networking

The game uses Unity Netcode for GameObjects to implement multiplayer functionality. RPCs are used for network communication, alongside peer-to-peer networking to host multiplayer sessions.

### Combat System

Combat interactions are handled through hitbox and hurtbox collision detection. A combo system allows attacks to be chained together.

### Character Animations

The game features fully rigged 3D characters from Mixamo.
